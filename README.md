# 🚇 오늘도 영업 중! 역내 매점

지하철역 안의 작은 매점을 운영하는 브라우저 시뮬레이터 게임입니다.
상품을 발주하고, 진열하고, 출근 러시부터 막차 시간까지 손님을 응대해 매점을 키워 보세요.

## 실행 방법

- 로컬: `index.html`을 브라우저에서 열면 바로 실행됩니다. (서버, 로그인, API 불필요)
- GitHub Pages: 저장소 **Settings → Pages → Branch: `main` / `(root)`** 로 설정하면 `https://<사용자명>.github.io/<저장소명>/` 에서 플레이할 수 있습니다.

## 게임 방법

1. **발주** → 2. **진열** → 3. **영업(실시간 6분)** → 4. **손님 응대** → 5. **정산**
- 손님 말풍선의 상품을 눌러 바구니에 담고, 봉투·영수증·길 안내 요청까지 마치면 **계산**합니다.
- 인내심 바가 절반 넘게 남았을 때 응대하면 팁과 평판을 더 받습니다.
- 놓쳐도 게임은 계속됩니다.
- 단축키: `1`~`4` 손님 선택, `Enter` 계산, `Space` 일시정지

## 특징

- 단일 HTML 파일, 외부 라이브러리 없음
- 진행 상황은 브라우저 로컬 저장소(`localStorage`)에 저장
- 데스크톱·모바일 대응, 다크 모드 지원
- 손상된 저장 데이터는 보정 또는 백업본으로 복구, 설정에서 내보내기/불러오기/초기화 가능

## 데이터 확장

`index.html` 안의 `PRODUCTS`(`P`), 손님(`C`), 사연(`ST`), 업그레이드(`UP`) 배열에 항목을 추가하면 게임에 반영됩니다.

## 현재 범위 (MVP)

- 돌발 이벤트: 비 오는 날, 열차 지연, 도매상 특가
- 제외: 효과음, 사연 도감, 그 외 이벤트 (후속 버전 후보)

## 앱으로 설치 (PWA)

GitHub Pages 같은 https 주소에서 열면 앱처럼 설치할 수 있고, 설치 후에는 오프라인에서도 실행됩니다.
- Android/Chrome·Edge: 주소창 메뉴 → **앱 설치** 또는 **홈 화면에 추가**
- iPhone/Safari: 공유 버튼 → **홈 화면에 추가**
- 파일: `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` 를 `index.html`과 같은 폴더에 두어야 합니다.
- 게임을 수정해 다시 배포할 때는 `sw.js`의 `CACHE` 이름(`subway-kiosk-v1`)의 숫자를 올리면 업데이트가 반영됩니다.
